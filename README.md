## Overview
This project demonstrates the use of Landsat-9, Sentinel-2 and NAIP imagery in Google Earth Engine to create cloud-free composites clipped to Knox County, TN.

Each dataset was filtered by date, region and cloud percentage. Median composites were used to reduce noise and enhance visualization clarity. The final outputs were styled with red county boundaries and transparent fills to emphasize the area of interest.
